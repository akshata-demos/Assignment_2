Setting up and Initializing Repositories:

git init: Creates a new, empty Git repository or reinitializes an existing one.
git clone <url>: Clones an existing repository from a specified URL.
git config: Sets configuration variables for Git, such as user name and email.

Working with Changes (Staging and Committing):

git add <file(s)>: Stages changes from specific files for the next commit.
git add .: Stages all changes in the current directory for the next commit.
git status: Shows the working tree status, including staged, unstaged, and untracked files.
git commit -m "message": Records staged changes permanently in the repository's history with a descriptive message.
git diff: Shows changes between the working directory and the staging area, or between commits.
